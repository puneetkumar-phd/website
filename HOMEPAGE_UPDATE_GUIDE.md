# Homepage update guide

This version adds:

- An expanded research biography
- A professional portrait area on the homepage
- Eight expandable computational-skill categories
- A labelled profile-photo placeholder
- Responsive styling for desktop and mobile screens

## Files changed

```text
index.html
assets/css/styles.css
assets/img/profile-photo.jpg
README.md
```

## Update an existing GitHub repository

You do not need to upload the complete `assets` folder again. Replace the files one at a time.

### 1. Replace index.html

1. Open the main page of your GitHub website repository.
2. Select **Add file > Upload files**.
3. Upload the updated `index.html`.
4. Commit with the message `Update homepage biography and skills`.

### 2. Replace styles.css

1. In the repository, open `assets`, then `css`.
2. Select **Add file > Upload files**.
3. Upload the updated `styles.css`.
4. Commit with the message `Update homepage styling`.

### 3. Add or replace the portrait

1. Prepare a passport-style portrait photograph, not a scan of your passport document.
2. Crop it vertically, preferably to a 4:5 ratio.
3. Name it exactly `profile-photo.jpg`.
4. In the repository, open `assets`, then `img`.
5. Select **Add file > Upload files** and upload the photograph.
6. Commit with the message `Add profile photograph`.

The HTML already points to `assets/img/profile-photo.jpg`, so no code change is needed after the photograph is uploaded.

## Recommended photograph

- Vertical 4:5 crop
- At least 800 x 1000 pixels
- Neutral or uncluttered background
- Head and upper shoulders visible
- Good natural lighting
- JPG format
- Preferably below 2 MB

Do not publish passport numbers, dates of birth, signatures, identification pages, or other identity-document information.
